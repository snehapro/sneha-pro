# SNEHA PRO — Audio | Visual | Lighting

Production marketing site for SNEHA PRO live audio engineering, built from the supplied visual reference.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Stack

- React + Vite
- Custom CSS (glass, neon, mobile-first)
- Lucide icons
